    Normalizer

    Bases: Model

    Main Normalizer class for generic text. Normalize unicode, hyphens, quotes, whitespace. By default, the normal form NFKC is used for unicode normalization. This applies a compatibility decomposition, under which equivalent characters are unified, followed by a canonical composition. See Python docs for information on normal forms: http://docs.python.org/2/library/unicodedata.html#unicodedata.normalize

    __call__(text)

    Calling a normalizer instance like a function just calls the normalize method.

    normalize(text)

    Run the Normalizer on a string. :param text: The string to normalize.

    Stopwords

    Bases: Model

    A word is a stopword when stopwords_fn returns True for it or it is in the loaded list.

    The set operators combine that rule, not just the lists: a | b and a + b match a word either operand matches, a & b one both match, a - b one a matches and b does not, and a ^ b one exactly one operand matches. The result keeps the operands' lowercase; operands that differ in lowercase raise ValueError, and so does & when both have a stopwords_fn (the result would have no finite list).

    name: stopwords lowercase: true stopwords_fn: stopwords_list: stopwords_path: nltk_stopwords_lang: verbose: False
